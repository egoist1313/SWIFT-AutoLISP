# AutoLispSwift v6.5

Набор AutoLISP-инструментов для AutoCAD Civil 3D — работа с трубопроводными сетями, геодезическими профилями и сечениями.

## Архитектура

- **Точка входа:** `load_all.lsp` — автозагрузчик с обновлением через GitHub/GitFlic
- **Паттерн:** каждый файл = одна команда `(defun c:COMMAND ...)`
- **DCL-диалоги** создаются в памяти через `vl-filename-mktemp`
- **Состояние** сохраняется между сеансами через `setenv` / `getenv`
- **COM-интеграция** через `vl-load-com` + `vlax-ename->vla-object`
- **Совместимость:** Civil 3D 12.0–13.8 (адаптивный поиск ProgID)

## Версии файлов

Актуальные версии хранятся в `.version`. Обновление запускается командой `UPDATE` через `load_all.lsp`.

Принудительное обновление (перескачать всё): `UPDATE-FORCE`.

### load_all.lsp

#### Для пользователей

- `UPDATE` — проверяет версии файлов на сервере и скачивает только изменившиеся.
- `UPDATE-FORCE` — принудительно перескачивает все файлы независимо от версий.
- Если сервер недоступен — автоматически загружает локальные файлы из папки.

#### Для разработчиков

- **Фикс:** `*error*` не завершался `(princ)` — оставлял мусор в командной строке AutoCAD.
- **Фикс:** `load-lsps` считал `(length lst)` в знаменателе, включая `SWIFT.mnu` — выводил "1 из 23" вместо "1 из 22 .lsp". Введён счётчик `lsp-count`.
- **Фикс:** `download-file` удалял оригинальный файл до успешного скачивания — при сбое сети файл терялся безвозвратно. Теперь скачивание идёт во временный `.tmp`, валидируется (проверка `SWIFT-START/END`), и только после этого `.tmp` переименовывается в целевой файл.
- **Новое:** бэкап перед обновлением — перед заменой файла старая версия копируется в `backup/имя_YYYY-MM-DD.bak`. Повторный бэкап за тот же день не перезаписывается.
- **Новое:** lock-файл `_SWIFT_LOCK.txt` защищает от двойного запуска UPDATE (автозапуск + ручной, два AutoCAD из одной папки). Lock старше 15 минут считается зависшим и сбрасывается автоматически.
- **Новое:** тихий режим при автозапуске — при загрузке AutoCAD UPDATE работает молча, выводит только ошибки. Ручной `UPDATE` показывает полный лог.
- **Новое:** безопасная загрузка меню — `_.MENULOAD` обёрнут в `vl-catch-all-apply`, WSAUTOSAVE гарантированно восстанавливается даже при ошибке загрузки `.mnu`.
- **Новое:** офлайн без `.version` → сообщение об ошибке и завершение. Слепая загрузка всех `*.lsp` из папки убрана.

## Changelog

### zac.lsp

#### Для пользователей

- Команда `ZAC` сохраняет все открытые чертежи и закрывает AutoCAD.
- **Да** — все чертежи сохраняются на своих местах и AutoCAD закрывается. Новые чертежи (ещё ни разу не сохранённые) и чертежи "только для чтения" автоматически сохраняются в папку "Мои Документы" с именем вида `Чертеж1_2026-05-02_14-30-25.dwg`.
- **Нет** — на случай если нажал случайно: все чертежи сохраняются как резервные копии во временную папку (`C:\Windows\Temp`), после чего AutoCAD закрывается. Оригиналы не изменяются, но копии останутся.

#### Для разработчиков

- **Фикс:** при "Нет" ранее вызывался `vla-SaveAs` в формате `acR12_dwg` — потеря Civil 3D объектов. Заменено на `vla-SaveAs` без указания формата (текущий DWG) + `_.QUIT _Y`.
- **Фикс:** проверка нового документа через `(vla-get-Path doc) = ""` не работала — Civil 3D выставляет `Path` в папку шаблона. Исправлено на `(vla-get-FullName doc) = ""`.
- **Фикс:** `vla-Save` не выбрасывает ошибку для новых документов — сохраняет молча в неизвестное место. Убрана попытка перехвата через `vl-catch-all-apply`, проверка переведена на `FullName`.
- **Новое:** `_zac-my-documents` — получает путь к "Моим Документам" через реестр `HKCU\...\Shell Folders\Personal`, корректно работает с OneDrive-редиректом и локализацией. Фолбэк на `%USERPROFILE%\Documents`.
- **Новое:** `_zac-timestamp` — штамп времени из `(getvar "CDATE")` в формате `YYYY-MM-DD_HH-MM-SS`.
- **Новое:** read-only чертежи (`vla-get-ReadOnly = :vlax-true`) при "Да" идут в Документы через `vla-SaveAs`, а не вызывают ошибку.
- **Рефакторинг:** убрана вспомогательная функция `save-and-close-all-documents`, все переменные локальные (`/ ...`), добавлен `*error*`.

### D.lsp

#### Для пользователей

- Команды `D+` / `Д+` добавляют символ `Д` перед текстом (или перед второй строкой у двустрочных объектов).
- Команды `D-` / `Д-` убирают `Д`. Если `Д` нет — объект не трогается.
- Работает с текстами, мтекстами, выносками и размерами.

#### Для разработчиков

- **Фикс:** `entget` вызывался 3 раза на одну итерацию для одного объекта. Тип закэширован в `etype` — один вызов на объект.
- **Фикс:** `strcase` вокруг проверки символа `Д` — бессмысленен, `strcase` работает только с ASCII (A–Z). Убран.
- **Рефакторинг:** двойной `cond` в ветках add/remove заменён на `if` — достаточно двух ветвей.
- **Новое:** добавлен `*error*` обработчик.
- **Фикс:** `D-` не срабатывал на текстах с MTEXT-форматированием (`{\H2.5;Д150}`, `{\fArial;Д150}` и т.д.) — `(substr txt 1 1)` возвращал `{`, а не `Д`. Добавлен парсер `_d-content-start` который пропускает `{}`, `\H...;`, `\W...;`, `\C...;`, `\f...;`, `\L`, `\O`, `\K` и находит позицию первого видимого символа. Выделены функции `_d-add` / `_d-remove`, оба работают через этот парсер.
- **Исправлена кодировка** файла: был Windows-1251, переведён в UTF-8.

### Delverts.lsp

#### Для пользователей

- Команда `DELVERTS` удаляет вершины полилинии по номерам. Вводить через запятую: `6,7` или `6, 7` (пробелы теперь тоже работают).
- Если после удаления остаётся слишком мало вершин — полилиния не изменяется, выводится предупреждение.

#### Для разработчиков

- **Фикс:** `(mapcar '1- vertnums)` пересчитывался на каждой итерации внутреннего цикла (O(n²)). Вынесен в `idx0` до цикла.
- **Фикс:** `(length vertlist)` вызывался на каждой итерации цикла. Закэшировано в `total`.
- **Фикс:** `append` в цикле перестраивал список каждый раз (O(n²)). Заменено на `cons` + `reverse` после цикла (O(n)).
- **Фикс:** пробелы в вводе ("6, 7") вызывали `atoi " 7" = 0`. Добавлен `vl-string-trim` для каждого токена.
- **Фикс:** минимум вершин для замкнутой полилинии — 3 (6 координат), для открытой — 2 (4 координаты). Раньше было 4 координаты для всех.
- **Новое:** добавлен `*error*` обработчик, `vl-load-com` вынесен на верхний уровень.
- **Рефакторинг:** `split-string` (глобальная) переименована в `_dv-split` (топ-уровень), убрана из тела `defun`.

### TurnObjects.lsp

#### Для пользователей

- Команда `TurnObjects` поворачивает выбранные объекты вокруг центра их bounding box.
- Угол задаётся в диалоге (в градусах). Последнее значение запоминается между сеансами.
- Режим «Случайный» — каждый объект с вероятностью ~50% поворачивается, остальные пропускаются.

#### Для разработчиков

- **Фикс:** `defun rand` и `defun C:ПОВЕРНУТЬОБЪЕКТЫ` определялись ВНУТРИ тела `C:TurnObjects` — оба становились глобальными только после первого запуска команды. Вынесены на верхний уровень.
- **Фикс:** `(vl-load-com)` был внутри `defun` — вынесен на верхний уровень.
- **Фикс:** `(vl-file-delete dcl_temp)` вызывался только в happy path — временный DCL файл утекал при любой ошибке. Удаление добавлено в `*error*` обработчик.
- **Новое:** добавлен `*error*` обработчик с очисткой DCL (`unload_dialog` + `vl-file-delete`).
- **Рефакторинг:** `rand` переименована в `_to-rand`, seed хранится в `*to-seed*`; DCL создаётся через `vl-filename-mktemp` вместо фиксированного имени.
- **Рефакторинг:** вложенные `if`/`progn` диалогового флоу заменены последовательным: load → new_dialog → start → unload, каждый шаг с явным `exit` при ошибке.
