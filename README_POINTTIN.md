# POINTTIN v1.4

Инструмент проецирования точек на TIN-поверхность в AutoCAD Civil 3D с поддержкой пользовательской системы координат (ПСК).

## Возможности

- **Две режима работы:**
  - Использование готовых точек из чертежа
  - Автоматическая генерация сетки точек с заданным шагом

- **Поддержка контуров:**
  - LWPOLYLINE (лёгкая полилиния)
  - POLYLINE (3D полилиния)
  - 3DPOLYLINE
  - AECC_FEATURE_LINE (характерная линия Civil 3D)
  - SPLINE (сплайн)
  - LINE (отрезок)

- **Исключение внутренних границ:**
  - Выбор контуров-отверстий для исключения из сетки
  - Точки расставляются вдоль всех контуров (внешний и внутренние)

- **Работа с ПСК:**
  - Сетка строится в координатах текущей ПСК
  - Высоты получаются из TIN-поверхности (в МСК)
  - Полная поддержка произвольных пользовательских систем координат

- **Обработка точек вне поверхности:**
  - Автоматическое смещение вне поверхности к ближайшей точке TIN
  - Маркировка красным цветом (группа 62 = 1)

- **Случайные смещения:**
  - По координатам (X, Y) с заданным диапазоном
  - По высоте (Z) с заданным диапазоном
  - Применяется только к точкам на поверхности (не к красным)

- **Сохранение настроек:**
  - Все параметры сохраняются в переменных окружения
  - При следующем запуске восстанавливаются последние значения

## Установка

1. Скопировать файл `pointTin.lsp` в папку AutoCAD
2. Загрузить в AutoCAD:
   ```
   (load "pointTin.lsp")
   ```
   или использовать файл ЗАГПРИЛ (Load Applications)

## Использование

### Запуск команды
```
POINTTIN
```

### Диалог параметров

1. **Поверхность TIN** — выбрать из списка доступных поверхностей
2. **Использовать заданные точки** — включить для выбора готовых точек из чертежа
3. **Шаг сетки точек** — расстояние между точками в сетке (значение > 0)
4. **Исключить внутренние границы** — включить для выбора контуров-отверстий
5. **Случайное смещение по высоте** — добавить случайное смещение Z
6. **Случайное смещение по координатам** — добавить случайное смещение X, Y

### Рабочий процесс

#### Режим готовых точек
1. Включить опцию "Использовать заданные точки"
2. Нажать OK
3. Выбрать точки (POINT) в чертеже

#### Режим автоматической сетки
1. Оставить опцию отключённой
2. Ввести шаг сетки
3. Нажать OK
4. Выбрать внешний контур
5. Если включена опция исключения — выбрать внутренние контуры (или Escape)
6. Инструмент создаст сетку и точки вдоль границ

### Параметры смещения

**Случайное смещение по высоте:**
- Применяется к точкам на поверхности
- Не применяется к точкам вне поверхности (красные, цвет 1)
- Пример: мин. -0.5, макс. 0.5 — смещение ±50 см

**Случайное смещение по координатам:**
- Применяется ко всем точкам
- Применяется ПОСЛЕ проецирования и смещения к поверхности
- Пример: мин. -0.3, макс. 0.3 — смещение ±30 см по X и Y

## Примеры

### Сетка точек в области с отверстиями
```
Шаг сетки: 10.0
Исключить внутренние границы: ДА
Выбрать внешний контур: [выбрать полилинию периметра]
Выбрать внутренние контуры: [выбрать контуры отверстий]
```
Результат: сетка заполнит область между внешней границей и отверстиями, 
точки будут расставлены вдоль всех контуров.

### Готовые точки с проецированием
```
Использовать заданные точки: ДА
Выбрать точки: [выбрать существующие точки]
```
Результат: все выбранные точки проецируются на TIN, 
вне поверхности смещаются к ближайшей точке TIN.

### Добавление шума к координатам
```
Случайное смещение по координатам: ДА
Мин. смещение координат: -0.5
Макс. смещение координат: 0.5
```
Результат: каждая точка получит случайное смещение до ±0.5 в координатах X и Y.

## Технические детали

### Системы координат
- **Координаты контуров:** получаются в МСК через `vlax-curve-getPointAtParam`
- **Сетка:** строится в координатах текущей ПСК через `trans 0 1`
- **Проецирование:** координаты передаются в МСК в `FindElevationAtXY`
- **Результат:** точки хранятся в МСК (стандарт AutoCAD)

### Проверка точек на принадлежность полигону
Используется алгоритм ray casting для определения нахождения точки внутри многоугольника.
Поддерживает как выпуклые, так и невыпуклые полигоны.

### Случайные числа
ПРГЧ со стандартным линейным конгруэнтным методом (LCG).
Инициализируется системным временем для случайности.

### Обработка ошибок
- Все операции с кривыми обёрнуты в `vl-catch-all-apply`
- Точки вне поверхности маркируются красным цветом
- Информативные сообщения об ошибках в командной строке
